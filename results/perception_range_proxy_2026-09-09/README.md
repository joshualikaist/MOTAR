# range 오차 대리 측정 — 판정 `RANGE_ERROR_LARGE` (2026-09-09)

계약: [`docs/plans/prereg_2026-09-09_range_error_proxy.md`](../../docs/plans/prereg_2026-09-09_range_error_proxy.md),
실행 전 등록. 수치는 [`report.json`](report.json), 입력 해시와 runtime은 [`receipt.json`](receipt.json).
NPS **validation만** 사용했고 `test_used: false`다.

거리 GT도 intrinsics도 없이 **상대** range 오차의 크기만 잰다. 목적은 오차 모델을 만드는 것이
아니라 **실사 거리 GT를 확보할 비용을 치를 가치가 있는지 판정**하는 것이다.

## 결과

단일-GT 1,310프레임. 대리 A는 선택·hit 프레임 965개(미선택 134, 비-hit 211 제외).

| 지표 | 중앙값 | IQR | \|오차\| P50 | \|오차\| P95 |
|---|---:|---|---:|---:|
| **대리 A — 검출기 박스 크기** | −3.2 % | [−19.4, +21.8] % | **20.3 %** | **51.4 %** |
| **대리 B — 겉보기 크기 시간 잔차** (W=5) | 0.0 % | [−0.0, +0.0] % | 0.0 % | **12.6 %** |

`E95 = max(51.4, 12.6) = 51.4 %` → 사전등록 문턱 30 % 초과 → **`RANGE_ERROR_LARGE`**.

### 사전 예측이 틀렸다

계획 문서와 사전등록 §0은 **자세에 따른 겉보기 크기 변동(대리 B)이 지배적**일 것이라 적었다.
측정은 반대다 — 지배항은 **검출기의 박스 크기 오차(대리 A)이고 대리 B의 4배**다.
가설 기각으로 기록한다.

### 크기 구간별 (대리 A)

| bin | 픽셀 | n | 중앙값 | \|오차\| P95 |
|---|---|---:|---:|---:|
| 1 | 8–16 | 172 | −0.0 % | 42.9 % |
| 2 | 16–32 | 648 | −5.8 % | 51.5 % |
| 3 | 32–64 | 145 | **+17.5 %** | **59.5 %** |

큰 표적일수록 나쁘다. bin 3에서 중앙값 +17.5 %는 검출기가 큰 표적의 박스를 **작게** 잡는다는 뜻이고
(크기 기반 추정기라면 거리를 그만큼 **멀게** 본다), P3-F에서 confidence 0.25에 FP 15,911개였던 것과
같은 방향의 증상이다.

### 영상별 계통 편차 — 잡음이 아니라 bias

| clip | n | 중앙값 | IQR |
|---|---:|---:|---|
| Clip_14 | 57 | **+28.3 %** | [+19.7, +36.6] |
| Clip_26 | 472 | +4.9 % | [−19.7, +24.1] |
| Clip_34 | 46 | +3.1 % | [−17.0, +22.5] |
| Clip_36 | 15 | **−34.0 %** | [−37.8, −29.8] |
| Clip_37 | 100 | +5.3 % | [−8.1, +23.6] |
| Clip_41 | 233 | **−16.0 %** | [−20.2, −10.0] |
| Clip_50 | 42 | +14.6 % | [−11.3, +27.1] |

영상 안에서는 IQR이 좁고 영상 사이에서 중앙값이 −34 %에서 +28 %까지 흩어진다. 즉 오차의 상당 부분이
프레임별 잡음이 아니라 **한 영상(=한 교전) 내내 유지되는 계통 편차**다. 제어 관점에서는 이쪽이
프레임 잡음보다 중요하다 — 에피소드 내내 거리를 일정 비율로 잘못 보는 것과 같다.

## 해석의 한계

- **대리 B의 중앙값 0은 자세 변동이 없다는 뜻이 아니다.** 5점 중앙값 필터는 단조 구간에서 중앙
  표본을 그대로 돌려주므로 잔차가 정확히 0이 된다. 즉 대리 B는 **반전(고주파)만** 보고 매끄러운
  성분은 구조적으로 못 본다. 따라서 P95 12.6 %는 자세 항의 **빠른 성분**에 대한 상한이며,
  느린 자세 변화는 여전히 미측정이다. 다른 평활자를 쓰려면 별도 사전등록이 필요하다.
- **hit 문턱 IoU 0.3은 느슨하다.** IoU 0.3짜리 박스는 크기가 크게 달라도 hit로 세어지므로 대리 A의
  꼬리 일부는 매칭 느슨함에서 온다. 더 엄격한 문턱은 별도 사전등록 대상이다.
- **크기 기반 추정기를 가정한 값이다.** 스테레오·depth로 거리를 얻는 설계라면 이 수치는 다른
  추정기의 오차다.
- **절대 미터 아님.** intrinsics가 없다. 느린 bias(기체 실제 크기 가정 오류)도 못 본다.

## 이 결과가 바꾸는 것

지배항이 **검출기 박스 크기**로 밝혀졌고, 그것은 거리 GT 없이 주석만으로 **이미 전수 측정된다**.
거리 GT가 반드시 필요한 항(자세에 의한 겉보기 크기 변동)은 빠른 성분 기준 12.6 %로 지배항의 4분의 1이다.

따라서 실사 거리 GT 확보는 **지배항을 재기 위해 필요한 것이 아니다.** 이 판정은
`RANGE_ERROR_LARGE`이지만, "그러므로 MIDGARD류 자료가 필요하다"로 곧장 이어지지 않는다.
후속 판단은 `docs/plans/perception_to_interception_plan_2026-09-09.md` §1-A에서 갱신한다.

## 주장하지 않는 것

절대 미터 오차, 느린 자세 변화의 크기, test split에 대한 어떤 것, 그리고 이 51.4 %를 그대로 현재
시뮬레이터에 주입해도 된다는 것 — 시뮬 표적은 반지름 0.15 m **구**라 자세에 의한 겉보기 크기 변동이
원리적으로 없고, 시뮬 range는 크기 역산이 아니라 해석적 ray-cast depth(`navrl_perception.py:1662`)다.
