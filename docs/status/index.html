05 / SPEED

표적이 빨라져도 버티는가

25막대에서 표적 속도를 0 → 1.5 m/s로 올리며 측정했습니다. 드론이 2.5 m/s로 충분히 빠르기 때문에 속도 축은 거의 평탄합니다. 장애물 토큰 선택 범위를 360°에서 240°로 좁힌 결과의 정면 비교입니다.

06 / CAMPAIGN

무엇이 실제로 통했나

고정 스폰 baseline부터 현재까지의 개입 순서입니다. 고도 관련 3연속 개입은 포획률만 올리고 막대 충돌은 13%에서 전혀 못 건드렸습니다. 충돌이 움직인 것은 장애물 표현을 바꾼 뒤부터입니다.
