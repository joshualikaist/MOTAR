장애물과 드론을 센서에서 직접 구분하고, 가림 동안 belief를 유지합니다.

정보 방화벽: actor에는 detector/tracker가 추정한 값만 전달하고, simulator의 GT 표적 위치는 critic·reward·평가 label에만 사용합니다. 이 분리가 완료되기 전 결과는 “완전 자율 탐지”로 주장하지 않습니다.
