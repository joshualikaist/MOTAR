이 시스템의 동작을 결정하는 환경변수 전량. 값을 손으로 옮겨 적은 표가 아니라 소스에서 생성한 것이라, 코드가 바뀌면 여기도 바뀐다. 각 knob이 무엇을 하는지는 소스 주석을 그대로 가져왔고, 통제 실험으로 검증한 적이 있는지를 함께 표시한다 — "런처에서 값만 지정했다"와 "A/B로 효과를 분리했다"는 전혀 다른 이야기다.

동작을 바꾸지 않는 이름들

환경변수를 읽는 지점이 모두 파라미터인 것은 아니다. 함수 본문 안에서 os.environ.get으로 읽는 대부분은 자기 설정을 영수증·매니페스트에 기록하려고 다시 읽는 것이며(NavRLTask.get_env_state 등), 동작에는 영향을 주지 않는다. 런처 전용 플래그도 마찬가지다. 그런 이름은 위 목록에서 빼고 아래에 접어 둔다.
