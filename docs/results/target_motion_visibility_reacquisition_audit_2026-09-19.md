* **visible -> invisible transitions** — navrl_task.py:5525 counts `prev_visible & ~visible & valid_y_now`, i.e. strictly the visible->hidden direction, and only between two VALID observations.
* **invisible -> visible transitions** — An episode starts hidden, so hidden->visible count equals visible->hidden count, plus one if the episode ended visible. The terminal visibility flag is NOT exported, so the derived count is bounded to +/-1 per episode and is not reported as a point value.
* **reacquisition count** — Equals the derived hidden->visible count minus the first acquisition, inheriting the same +/-1 per-episode bound.
* **loss duration** — No per-loss duration accumulator exists anywhere in the task.
* **maximum loss duration** — Same: no duration state is kept per loss.
* **track age** — search_state carries belief coverage, not a track-age counter.
* **lost-track duration** — Not accumulated.
* **first acquisition latency** — Not on the original wish-list, but present and directly relevant.
* **never-acquired rate** — Not on the original wish-list; it turns out to carry the clearest signal.

Nothing was reconstructed beyond what the aggregate export supports. The three duration metrics are absent outright and are reported as `NOT_RECORDED` rather than approximated.

## 3. What this changes about the mechanism reading

In **95.42%** of E0 timeout episodes the target was **never acquired even once**, against 83.01% (E1), 84.11% (H) and 84.38% (E2).

That is a different statement from the one the visibility fraction supported. The step-weighted fraction was consistent with *losing* a target and not getting it back. The acquisition record says the dominant failure is earlier than that: for a static target the policy frequently **never makes first contact at all**.

The same ordering appears in the crash class, where every arm does acquire more often than in timeouts but the arms stay ordered the same way:

| arm | never acquired, crash episodes |
|---|---:|
| E0 static | 78.05% |
| E1 CV | 60.69% |
| H historical | 61.74% |
| E2 obstacle-aware | 54.38% |

Among captures, acquisition is near-universal in every arm (never-acquired at or below 0.07%), and the arms separate instead on **how quickly** they acquire: E2 obstacle-aware 58.0, H historical 60.9, E0 static 66.1, E1 CV 70.2 observation steps to first sight.

Fused and camera acquisition agree exactly in every row, so the camera is the binding source here; no fusion path rescued an episode the camera missed.

## 4. Bounded interpretation

> The acquisition record is consistent with a **first-contact** rather than purely a reacquisition account: under this frozen policy, a static target that is not found early is frequently never found, whereas moving targets generate the relative motion that leads to first sight. Visibility and acquisition both order the arms the same way as close-approach success.

This remains an **association**. No mediation or counterfactual experiment was run, and none is authorised here. In particular this audit does not establish that acquisition failure *causes* the close-approach difference, because the same target motion that changes acquisition also changes everything downstream of it.

The pooled step-weighted visibility estimator retains its caveat — it weights longer episodes more heavily and is not an unconditioned per-episode mean:

## 5. What would still need new data

Loss duration, maximum loss duration and track age are `NOT_RECORDED`. A causal test of the reacquisition account would need a preregistered experiment that holds first-contact geometry fixed while varying only target motion — which is new data collection, outside this task.

```text
REACQUISITION_TRANSITION_METRICS = PARTIALLY_RECORDED
  visible_hidden_transitions      = RECORDED_DIRECTLY
  hidden_visible / reacquisition  = DERIVABLE_FROM_FROZEN_DATA (+/-1 per episode)
  loss_duration / track_age       = NOT_RECORDED
```
